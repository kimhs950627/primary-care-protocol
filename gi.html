Chapter 05 · GI

소화기 약속처방 — 먼저 red flag, 다음이 약

복통·설사·변비·IBS 외래 처방과 급여·청구 기준을 정리한 내부 프로토콜.

원노트: 일차의료 소화기 약속처방 프로토콜 v1.2개인 학습 정리

01 — Note공통 원칙

기질적 원인·위장관 외 질환 배제 → Red flag 확인 → 기능성 질환 고려 → 대증 치료 → 재평가·의뢰 기준 차팅

02 — Note복통

Red flag

혈변·흑색변·토혈, 황달, 분출성 구토, V/S 불안정, rebound tenderness, 고열, 밤에 깨는 복통, 등 방사 통증, 체중 감소, 빈혈, 복부 종괴, 상복부 통증+식은땀+고령(심근경색 감별)

기질성 감별

  • 등 방사(췌장·대동맥박리)
  • 기름진 음식+야간(담즙산통·PUD)
  • 식은땀+고령(MI)
  • 우상복부+발열(담낭염)
  • 수술력+colicky(장폐색 — 진경제 금지)
  • AF+심한 diffuse 통증(장간막허혈)
  • 40세↑+위장약 불응+new DM+체중감소(췌장암)

기능성 감별

  • 배변 후 호전(IBS)
  • 식후 상복부(FD)
  • 식후 오심구토+DM(위마비)
  • 속쓰림(GERD)
  • Carnett(+)(복벽통증)

FD

40세 미만 alarm(-) → PPI+Prokinetics 8주 / 40세 이상·alarm(+) → 위내시경. EPS: PPI 우선, PDS: Prokinetics 우선. 불응 시 TCA 10mg(고령 EKG), Mirtazapine, Buspirone(F41.9)

복벽통증

1% lidocaine 4mL + triamcinolone 40mg 1mL trigger point 주사

03 — Note설사

급성 90% 감염성. 잠복기: 1~6h S.aureus·B.cereus / 8~16h C.perfringens / 16~72h ETEC·Salmonella·Shigella

검사 적응증

  • 탈수
  • 38.5℃↑
  • 혈성 설사
  • 대변 WBC(+)
  • 48시간 무호전
  • 최근 항생제
  • 50세↑+심한 복통
  • 70세↑
  • 면역저하자

수액·식사

수액: 경증 ORT 50mL/kg, 중등도 100mL/kg 4~6시간, 중증 정주 20~40mL/kg. 식사: 금식→미음→죽→밥→단백질→지방

지사제

  • Loperamide(비염증성만, 발열·혈변 금기)
  • Smectite(안전, 1~2시간 간격)
  • Racecadotril(비급여, 콜레라·EHEC 금기)

경험적 항생제

발열+혈변, 이질, 38.5℃↑ 여행자, 면역저하: Ciprofloxacin 500 BID 3일 또는 Azithromycin 500 QD 3일. STEC 의심 시 항생제 금기(HUS)

C. difficile

Metronidazole 500 TID 10~14일 또는 Vancomycin 125 QID 10~14일

식중독 질문 시

'음식으로 인한 급성 위장관염'으로 설명, 법정감염병 의심 시 보건소 신고

04 — Note변비

Red flag

체중감소·혈변·빈혈·가족력·가늘어진 변·배변습관 급변 → 대장내시경. 12주 불응 → 의뢰. DRE 배변실조 소견 → 의뢰

단계

  1. 생활습관(섬유질 20~35g, 서서히 증량)
  2. Bulking(아기오과립 급여)
  3. Osmotic(마그밀 급여·신장애 금기 / 듀락칸이지 급여·가스 / 폴락스산 비급여·가스 없음·노인 최우선)
  4. Stimulant 단기 rescue(듀오락스 최대 1주)
  5. Prucalopride(완하제 불응 만성변비 급여기준, 레졸로 비급여·루칼로 등 제네릭 급여, 65세↑ 1mg)

05 — Note과민성 장증후군 (IBS)

진단

ROME IV(6개월 전 시작, 최근 3개월 주 1일↑ 복통 + 배변 연관 2가지↑). ACG 2021: 양성 진단 전략, 최소 검사

Subtype

BSFS, 2주 배변일기: IBS-C(딱딱 변 >25%) / IBS-D(묽은 변 >25%) / IBS-M(둘 다 >25%) / IBS-U. 1년 내 절반 이상 subtype 변경 → 주기적 재평가

감별검사

  • IBS-D는 celiac 혈청(IgA tTG+총IgA), fecal calprotectin+CRP(IBD 배제)
  • alarm 없는 45세 미만 루틴 대장내시경 비권고(ACG), 국내는 적극 권고
  • 불응성 변비·골반저 증상 시 항문직장 생리검사

공통

  • low FODMAP 제한적 시행, 수용성 섬유(psyllium), 운동, peppermint oil, 장-뇌 심리치료(CBT·최면)
  • Probiotics는 국내 지침 보조 권고 vs ACG 비권고(근거 부족)

IBS-D

Loperamide(설사만 개선, 전반증상 무효) → Ramosetron 이리콜정(K58.1 급여, 남 5μg QD·여 2.5μg QD) / Rifaximin(타 약제 불응 시 2차, 7일 이내, JX999 기재) → 난치성 TCA

IBS-C

수용성 섬유 → 삼투성 완하제(PEG는 변비에는 1차이나 전반증상 근거 없음) → Prucalopride. 국외 전용(미도입): Linaclotide, Lubiprostone, Tegaserod

IBS-M/U

우세 증상 따라 교차, TCA 필요 시 Nortriptyline 선호(항콜린 적음)

복통

진경제 1차(국내) → TCA/SSRI. ACG는 진경제 근거 낮음, TCA 강한 권고

F/U

4~8주 재진, subtype 재평가. 1~2개월 무호전 시 다른 진단

06 — Note심평의학 핵심 (2026-08-26 검증)

복통 · 설사 · 변비 · 과민성 장증후군(IBS) — 외래 Routine Order (의사용). 근거: 일차진료_guideline 소화기 Ch.17~21, ACG 2021 IBS Guideline, 대한소화기기능성질환운동학회 IBS 지침. 심평의학 현행 고시 대조 완료(2026-08-26). 전체 원문은 HTML 파일 참조.

  • Ciprofloxacin: 고시 2017-77호 — 세균성 장감염 상병 시 1차 사용 가능, A090 청구 시 JX999 기재
  • Rifaximin: 고시 2013-127호 — 타 약제 불응 시 2차 원칙, JX999 필수, 7일 이내
  • Ramosetron: 고시 2025-88호 — 설사형 IBS 인정(이리보정 삭제, 이리콜정 급여)
  • TCA: IBS 투여 허가초과 급여 인정(K58.8/58.9)
  • Prokinetics 2종 병용 불가(1종만 급여) / 진경제는 별도 기준 없어 병용 가능
  • 향정신성(Etizolam 등): 1회 30일, 6개월간 214일 초과 시 전산심사
  • Lactulose: 일반약 변비 급여(소아 1mL/kg, 만성신부전 60mL까지)
  • 정장생균제: 6세 미만 급성감염성 설사·항생제 연관 설사·괴사성 장염만 급여, 이외 전액본인부담
  • Prucalopride: 완하제 불응 성인 만성변비 급여(제품별 상이)
